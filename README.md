# Odesa Sky Defense

Browser-based stylized real-time defense game prototype set in a compressed historic coastal city environment inspired by Odesa.

## Current milestone

Sprint 1:
- modular Three.js architecture
- tactical high-angle camera
- base terrain
- procedural sunset sky
- moving cloud layers
- sunset lighting and atmospheric fog

## Controls

- WASD / Arrow keys: move camera
- Q / E: rotate camera
- Mouse wheel: zoom

## Design constraint

All gameplay parameters for aerial threats and defense systems are fictionalized for game balance and do not reproduce real-world operational specifications.

## Roadmap

1. Scene and atmosphere
2. OpenStreetMap-based city geometry
3. Fictional aerial threat routes and markers
4. Abstract defense gameplay
5. Wave system
6. Atmosphere and polish
